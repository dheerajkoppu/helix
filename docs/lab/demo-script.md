## Check before recording

1. `make dev` is running: the API on `http://localhost:8000`, the web app on `http://localhost:3000`.
2. Simple mode is on (the "…" menu, Advanced off). In Advanced mode the screens show codes and technical terms and the quoted labels above do not match.
3. Open the reference run and read the step bar: "23 facts from 11 sources", "3 possible causes", "Chose 1 of 4 tests", "Test finished", "Answer changed". If any caption differs, fix the spoken line.
4. Replay speed is "1×". Run the replay once from start to end with a stopwatch: it should take about 70 seconds.
5. Watch the replay button. In 4 of 9 automated test captures the replay had stopped part-way, at record line 43 or 46, with the button reading "Play". The cause was not established; other people were editing the web app at that time, so make sure nobody edits files under `web/` while recording. If the button reads "Play", press it.
6. The 3D viewer loads on the variant page and on the Result step. Wait for it before you start.
7. Type `BTK` in the home search once and confirm the gene opens. If it does not, use the "BTK" chip under "Try a gene".
8. On `/lab`, read the numbers in "Team of agents vs one agent" and both run counts. Say the numbers on the screen. "Recent runs" may list rows that read "Running" while the repeat study is still going; that is fine.
9. The approval run still reads "Not approved" on the shape-check row.
10. The editor shows `lab/agents/orphafold_lab/config.yaml` in a large font, with the folder `lab/agents/orphafold_lab/agents/` open in the tree.
11. Do not press "Run" on `/lab` while recording. It starts a real run with real agents that takes several minutes.
12. Do not open the Compare stage for a new prediction, the Boltz-2 provider or the chat assistant on camera. Live structure predictions fail at present because the public ESMFold server returns errors; Boltz-2 has no GPU backend attached; the chat assistant needs an API key.

## Words to keep out

- "Proves", "discovered", "confirmed": the record says "Proposed by the agents. Not proven."
- "Faster": the measured comparison shows the team is slower than one agent, and no person was timed.
- "A scientist approved": the kept approval run timed out without a decision.
- Anything about patients, diagnosis or treatment. The Lab is for research and hypothesis generation only.
