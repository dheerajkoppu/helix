# OrphaFold

Open protein research for rare disease.

OrphaFold is an open-source research platform for computational rare-disease work. It follows one
path: disease, gene, pathogenic variant, protein, structural change, mechanism, candidate
interventions, research hypothesis. The first dataset is the IUIS classification of inborn errors of
immunity.

OrphaFold is a research and hypothesis-generation tool. It is not clinical decision software.

## Run it

Needs Python 3.14, Node.js and pnpm. No database, queue or API key is required.

```bash
make setup    # creates api/.venv, installs the API and the web dependencies
make dev      # API on http://localhost:8000, web on http://localhost:3000
```

The two halves can also be run on their own:

```bash
cd api && .venv/bin/uvicorn orphafold.main:app --port 8000     # or: make api
cd web && pnpm dev                                             # or: make web
```

API reference: http://localhost:8000/api/v1/docs. Every route is under `/api/v1`.

| Command      | Does                                                                               |
| ------------ | ---------------------------------------------------------------------------------- |
| `make setup` | Creates `api/.venv`, installs the API (`EXTRAS=dev,postgres,redis,s3`) and the web |
| `make dev`   | Runs API and web together; Ctrl-C stops both                                       |
| `make api`   | Runs the API (`RELOAD=1` restarts it when a file under `api/orphafold` changes)    |
| `make web`   | Runs the web dev server (`API_URL=http://host:port` to call another API)           |
| `make seed`  | Rebuilds `data/seed/catalog.json` from its sources (`SEED_ARGS="--refresh all"`)   |
| `make types` | Regenerates `api/openapi.json` and `web/src/lib/api/schema.ts`                     |
| `make check` | Strict API import, generated types are current, `tsc`, `eslint`                    |
| `make build` | Production build of the web app                                                    |
| `make lint`  | `ruff` over `api/`                                                                 |

## Configure it

Everything runs with no configuration. To change a setting, copy [`.env.example`](.env.example) to
`.env` in the repository root; it lists every setting of the API and the web app with its default.
PostgreSQL, a Redis job queue with separate workers, and S3-compatible artifact storage attach through
those settings.

## What is here

| Path             | Holds                                                                                        |
| ---------------- | -------------------------------------------------------------------------------------------- |
| `api/`           | FastAPI service, package `orphafold`: source adapters, seeded catalog, jobs, model providers |
| `web/`           | Next.js app: workspace, sequence axis, molecular viewer, explore                             |
| `data/seed/`     | The seeded dataset the API loads at startup, with its sources and build report               |
| `data/examples/` | Real cached model outputs for the development provider                                       |
| `docs/`          | Product brief, architecture, design system, research notes                                   |

- [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md): the backend, its contracts, and how to add a source
  adapter, a route, a model provider or a job kind.
- [`docs/DESIGN_SYSTEM.md`](docs/DESIGN_SYSTEM.md): the interface, its components and the rules for
  building pages.
- [`docs/PRODUCT_BRIEF.md`](docs/PRODUCT_BRIEF.md): what OrphaFold is built to do.

## Data

`data/seed/catalog.json` is generated by `make seed` from openly licensed sources and the identifiers
of the IUIS 2024 classification. `ATTRIBUTION.md`, `data/seed/SOURCES.json` and
`data/seed/build_report.json` are generated by the same build; do not edit them by hand. Field
meanings are in [`data/seed/README.md`](data/seed/README.md), and the licence and required citation
of every source are in [`ATTRIBUTION.md`](ATTRIBUTION.md).

Every biological statement shown comes from a database record with its source, release and retrieval
date. A value no source provides is shown as Unknown. Experimental structures, existing predictions
and predictions generated by OrphaFold are always labelled apart.
